# Nova Cart - Smart Merchant Inventory Hub 🚀
### Autonomous Neighborhood Supply Chain Optimization Engine

Developed for the **H2S Promptwars Hackathon** using an advanced prompt engineering and "Vibe Coding" workflow stack.

---

## 📊 The Core Business Challenge
Nova Cart's growth telemetry highlights a critical retention cliff: the platform's **repeat purchase rate collapsed from 41% to 27%** within 6 months. Operational analysis shows that **35% of all cancellations are caused by out-of-stock items** because local mom-and-pop stores take 1–3 days to manually synchronize online catalogs. This creates "phantom inventory," resulting in an 11% platform order cancellation rate and flooding support systems with 5,900+ tickets monthly.

## 💡 The Digital Intervention
We engineered a zero-friction merchant portal that fixes operational data accuracy right at the storefront level:
* **Natural Language Stock Parsing (Input → Logic):** Store owners type informal restocking notes (e.g., *"Added 20 packages of fresh milk"*). The system uses dynamic pattern parsing logic to update live metrics containers without requiring tedious inventory forms.
* **Predictive Demand Allocation (Logic → Output):** An interactive assistant cross-references regional commuter traffic indices to flag upcoming product run-outs by 6:15 PM, letting merchants manage stock buffers before cancellations occur.
